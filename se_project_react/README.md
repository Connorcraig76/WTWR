WTWR is a React-based web application that fetches real-time weather data and recommends suitable clothing based on the current temperature.

Features:

    - Live Weather Integration: Connects to the OpenWeather API to provide precise location-based temperature data.

    -Intelligent Recommendations: Dynamically filters your wardrobe to suggest clothing appropriate for hot, warm, or cold weather conditions.

    - Global State Management: Utilizes React Context to provide a seamless temperature unit toggle (Fahrenheit/Celsius) across the entire application.

    - Intuitive Navigation: Implements client-side routing via React Router to manage distinct views for the main dashboard and user profiles.

    - Data Persistence: Transitions from static assets to a dynamic backend-mimicking architecture, supporting full CRUD operations for your clothing collection.

    - Responsive Architecture: Built with a mobile-first, adaptive design for consistent performance across all devices.

Technologies Used:

    - Frontend: React.js, Vite, React Router, CSS

    - Data & API: OpenWeather API, json-server

    - Version Control: GitHub
